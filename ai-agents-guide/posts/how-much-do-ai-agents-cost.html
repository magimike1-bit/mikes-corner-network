How much do AI agents cost? The four ways you actually get charged

Money · 8 min read · Prices checked 13 October 2026

"How much does an AI agent cost?" sounds like it should have a simple answer. It doesn't — not because vendors are hiding the number, but because there is no single thing being sold. Depending on the product, you might be paying for a seat, for each action the agent completes, for a bundle of credits, or for the raw text the underlying model reads and writes. Each model bills differently, grows differently, and surprises you in a different place. This guide walks through all four, using prices taken from the vendors' own pricing pages on 13 October 2026.

General information only, not financial advice. Prices change often — every figure below was checked against the vendor's official pricing page on the date shown, in US dollars, before tax where a vendor notes tax is excluded. Always confirm the current price on the vendor's page before you buy.

The short version

For an individual, a capable agent product starts at about $20 a month on a subscription. For a team, per-seat business plans run from $20 to $100 per person per month depending on how much usage the seat includes. Platform products that let a whole organisation build agents charge in credits or tasks instead — hundreds of dollars a month is normal there. And if you build on a model API directly, you pay per token, which can work out to a few cents per task. Which of those is "the price of an AI agent" depends entirely on which shelf you are shopping on.

The four ways you actually get charged

1. Per seat. A flat monthly fee per person, like any other software subscription. Anthropic's Claude Pro costs $20 a month billed monthly, or $17 a month on an annual plan ($200 billed up front), and it includes Claude Code and the ability to hand off and schedule tasks. OpenAI's ChatGPT Business Standard seat is $20 per user per month billed annually ($25 billed monthly). The catch with seats is that the fee buys a usage allowance, not unlimited work — more on that below.

2. Per action unit. You pay for what the agent does, measured in the vendor's own unit. Automation platform Zapier counts a "task" each time a workflow successfully completes an action, and its plans are sold in monthly task allowances. Microsoft's Copilot Studio counts Copilot Credits, which are consumed whenever an agent performs a task or generates a response. The unit is easy to budget around — until you realise each vendor defines its unit differently.

3. Per token. If you build an agent on a model provider's API, there is no subscription at all. You pay for tokens — roughly, pieces of words — that the model reads (input) and writes (output). This is the cheapest way to run an agent at low volume and the easiest way to get a shocking bill at high volume, because every step, retry, and tool result in a long task adds tokens.

4. Custom. At the top end, pricing simply isn't published. OpenAI's Enterprise plan and Zapier's Enterprise plan are both "contact us" arrangements, and Microsoft sells Copilot Studio partly through prepaid and negotiated plans. If a vendor won't show you a number, expect the number to be large and negotiated.

Two details in that table matter more than the headline numbers. First, Microsoft is explicit that a varying number of Copilot Credits is billed depending on the specific usage — the same agent doing a harder job costs more credits, so the pack price is a ceiling on predictability, not a fixed cost per task. Two people on the same $20 plan can get very different amounts of agent work out of it.

A worked example: what 1,000 agent tasks cost on an API plan

Per-token pricing feels abstract until you run the arithmetic once. Take a modest agent task — say, reading a short document and drafting a reply — and assume it uses 20,000 input tokens and 3,000 output tokens per run. Those are illustrative assumptions, not measurements; substitute your own and the method still works. At Anthropic's published rates:

The lesson is not the specific totals — your tasks will differ. The lesson is the shape: model choice alone swings the same workload five-fold, from roughly $35 to roughly $175, and volume multiplies whatever you pick. It also explains why Anthropic prices tool use the way it does: tool calls are billed on the total input tokens sent, including the tool definitions themselves, plus the output tokens — an agent that makes many tool calls per task is paying for every one of those round trips. For work that doesn't need an instant answer, Anthropic's Batch API discounts both input and output tokens by 50%, which is the single easiest saving on this page.

The costs that are not on the price page

Overages. What happens when you hit a limit is part of the price. On Zapier, reaching your task limit switches you to pay-per-task billing at a higher per-task rate, unless you turn that off — in which case your workflows simply pause until the next usage period. On a Claude subscription, hitting a limit means waiting for the window to reset, moving to a higher plan, or turning on usage credits billed at standard API rates. Neither is a scandal; both are things you want to know before the busy week, not during it.

Retries and loops. Usage-based billing charges for attempts, not just successes — with one friendly exception: Zapier only counts an action when it completes successfully, and triggers and failed actions don't count. Token billing has no such mercy. An agent that retries a failing step ten times has bought ten runs. This is why the guide on what to do when an agent gets stuck belongs next to this one: on a metered plan, a looping agent is a billing problem, not just an annoyance. Relatedly, if an agent reaches your apps through Zapier's MCP connection, each tool call uses two tasks from your plan — chatty agents burn allowances faster than the sticker suggests.

Your checking time. Every agent output still needs the verification step described in the guide on checking an agent's work. That time is a real cost of running an agent, and it doesn't shrink just because the subscription does. Price it in honestly when you compare an agent against doing the task yourself.

Estimate your own bill in about ten minutes

  1. Name the job and count it. Pick one recurring task and estimate how many times a month it runs. Fifty times and five thousand times are different products.
  2. Decide which shelf you're on. One person doing varied work: a seat. A fixed workflow between apps: tasks. A team building many agents: credits. Building your own: tokens.
  3. Pull the current price for that shelf from the vendor's pricing page — not from an article, including this one. Prices checked on 13 October 2026 will drift.
  4. Do the unit math. Seats: fee x people. Tasks or credits: runs x units per run. Tokens: use the worked-example method above with your best guess at tokens per run.
  5. Add a slop factor. Retries, longer-than-average tasks, and overage rates all push real bills above the clean estimate. If the padded number still looks fine, the clean one will too.
  6. Check the limit behaviour — pause, pay-per-task, or wait for a reset — and pick the failure mode you can live with.

What success looks like: you can state, in one sentence, "this agent costs about $X a month at Y runs, and if it exceeds that, Z happens." If you can't fill in Z, you haven't finished estimating.

FAQ

Can I use an AI agent for free? Yes, at small scale. Claude has a $0 free plan, and Zapier's free plan includes 100 tasks a month. Free tiers are for learning what an agent does with your actual work — treat them as trials with longer clocks, not as a long-term plan.

Why did my bill spike? On usage-based pricing, the usual suspects are volume (more runs than expected), task length (longer documents and conversations consume more tokens or credits), model choice (a premium model costs several times a small one per token), and retries — an agent repeating a failing step bills every attempt.

Is a subscription or pay-per-token cheaper? It depends on volume, and the worked example shows why: at a few hundred modest tasks a month, per-token billing can come in well under a $20 seat; at heavy daily use, a flat seat with a usage allowance is predictable in a way a meter never is. Run both calculations with your own run count before deciding.
