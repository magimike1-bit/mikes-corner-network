Printer won't connect to Wi-Fi: fix it by failure stage

Fixes · 8 min read

The printer is probably not broken. Printers fail to join Wi-Fi at three distinct stages, and the stages look identical from across the room, a blinking light and no printing, while needing completely different fixes. Stage one: the printer never sees your network in its list. Stage two: it sees the network, you enter the password, and the join is rejected. Stage three: the printer joins happily, reports itself connected, and no computer or phone can find it. Restarting everything, the usual advice, treats none of these specifically. The printer already knows which stage it failed at, and it will print that information on a test page. Start there.

Read the stage off the printer's own test page

Most wireless printers can print a network configuration page or a wireless network test report from their settings or reports menu. HP's support guidance uses that report as the check on signal strength and connection status, and it is the right first move for any brand: the page states whether the printer is connected, which network name (SSID) it joined or tried to join, and where the wireless test failed. Match what it says to a stage:

StageWhat you observeWhere the fault sits
1. Cannot see itYour network name is missing from the printer's listBand, channel, or a hidden name, the router checklist below
2. Join rejectedNetwork is listed, password entered, connection failsPassword, security mode, or a router block
3. Joined but invisiblePrinter says connected; computers and phones cannot find itDifferent network than the device, or discovery blocked

One cause sits underneath stage three so often that HP lists it among the common ones: the printer is not on the same Wi-Fi network as the computer or phone trying to print. A printer that joined the guest network, or a 2.4 GHz network with a different name from the one the phone is on, is connected, and unreachable.

The fix procedure, by stage

  1. Print the configuration or test page first and note the stage, the exact network name shown, and any failure line. Every step below keys off that page; reprint it after a fix attempt instead of guessing whether anything changed.
  2. Stage 1, make the network visible to the printer. Move the printer into the same room as the router for setup; distance and walls can be sorted out after it joins. Then work the router checklist in the next section, band, channel, and name broadcasting are the three settings that hide a network from a printer while every phone in the house sees it fine.
  3. Stage 2, re-enter the password where you can see it. Printer keypads mangle passwords silently, so use a path that shows the characters. On Canon models, the documented route is the Network icon on the HOME screen, then Wi-Fi, then Wi-Fi setup, then Manual connect: choose your network, tap the password field, and use Show password so the entry is visible while typing, then tap OK. On HP models the documented route is Setup, then Network, then Wireless Setup Wizard: select the network and enter the password there. Passwords are case-sensitive on both.
  4. Stage 2, if the correct password still fails: Canon's documented next step is to turn the printer off, unplug the wireless router for 15 seconds, plug it back in, wait for it to come back fully, and try the join again. If it still fails on an HP, restore the printer's network settings. Setup, then Network, then Restore Network Defaults, and run the Wireless Setup Wizard again from a clean slate; the printer may be replaying stale settings from a previous network.
  5. Stage 3, put printer and device on the same network, by name. Compare the SSID printed on the configuration page with the network name shown in the phone or computer's Wi-Fi settings. They must match exactly. If the printer landed on a guest network or on a differently named band, reconnect it to the main network using the step 3 path, then reprint the configuration page to confirm the name.
  6. Stage 3, names match but discovery still fails: check the router for the settings that isolate devices from each other, a guest network's client isolation, or MAC address filtering left on. Apple's router guidance notes that MAC filtering can block devices; a filter list built for computers routinely forgets the printer. Move the printer to the main, non-isolated network rather than punching exceptions into the guest one.
  7. Print a real page from two devices, one computer, one phone, as the finishing test, not a printer self-test. A self-test proves the printer works. It says nothing about the network.

The router checklist printers actually fail on

Band. Many home printers detect only the 2.4 GHz band. HP's support community guidance is blunt about it: if the 2.4 GHz band is disabled or the router is running 5 GHz only, the printer's wizard shows nothing. Enable 2.4 GHz during setup.

Channel. The same guidance puts the printer's 2.4 GHz channel support at channels 1 to 11. A router set to channel 12 or 13, legal in many regions, invisible to the printer, produces a stage-one failure with no error anywhere. Set the 2.4 GHz channel to Auto, or explicitly to a channel from 1 to 11.

Security mode. Apple's recommended-settings page advises WPA3 Personal where everything supports it, and WPA2/WPA3 Transitional for compatibility with older devices, the transitional mode lets an older device join with WPA2 while newer ones use WPA3. A WPA3-only setting is a classic stage-two rejection for an older printer: the password is right and the join still fails.

Name broadcasting. A hidden network does not appear in any setup wizard. Either turn SSID broadcast on while you set the printer up, or use the printer's manual-entry option, if it offers one, and type the name exactly.

What success looks like: the reprinted configuration page shows the printer connected to the household's main network name, the same name the computer and phone show, the wireless light is steady rather than blinking, and a real document prints from both a computer and a phone without moving either device or the printer. If stage two survives the password check, the router restart, and the security-mode change, the remaining suspect is the printer's wireless hardware, and the test page from step 1 is the evidence to take to the manufacturer's support.
