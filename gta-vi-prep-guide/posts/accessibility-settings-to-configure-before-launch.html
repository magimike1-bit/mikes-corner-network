Accessibility settings to configure before launch day

Setup · Updated November 2026 · 8 min read

Turning on console captions does not settle accessibility for a new game. That is the misconception worth clearing first. The console baseline matters, and it is worth setting properly this month, but some features only work in games that support them, and a game can carry its own subtitle, remapping, and difficulty options that no system menu can set in advance. Two layers, two different jobs.

The facts box: Rockstar lists GTA VI as coming November 19, 2026 for PlayStation 5 and Xbox Series X|S. Rockstar has not, in the official material checked for this guide on November 3, 2026, announced the accessibility features inside GTA VI. Nothing below promises a feature in the game itself. Every setting named here is a documented console setting from PlayStation or Xbox.

Set the console baseline first

Start where both consoles keep these options together. On PS5, the home is Settings, then Accessibility. PlayStation lists display and text settings, screen reader, closed captions, chat transcription, mono audio, controller settings, and haptic feedback in that menu, and Accessibility can also be added to the control centre for quicker changes later.

Work through four groups in this order:

  1. Text and display. On PS5, open Display and Sound under Accessibility and set text size, bold text, and high contrast to readable levels. Turn on the colour filter and adjust its intensity if colour distinctions are hard to read. Reduce motion is there too, and inverting colours turns HDR off, so leave that one alone unless it is genuinely needed.
  2. Captions. On PS5, open Closed Captions under Accessibility, turn on Display Closed Captions, then open Closed Captions Settings, turn on Custom Caption Style, and set font size, colour, edges, and opacity, plus background colour and opacity. Small choices here decide whether captions survive a bright daytime scene.
  3. Audio. On PS5, mono audio for headphones sits at Settings, Sound, Audio Output, Headphones, Mono Audio for Headphones. It plays the same audio through both sides, which helps when hearing differs between ears or when one earbud is out to hear the room.
  4. Controls. On PS5, custom button assignments sit at Settings, Accessibility, Controllers, Custom Button Assignments for DualSense Wireless Controller. Pick the button, assign the function, then select Apply. Do the remapping now, in a menu with no timer and no mission running.

On Xbox, the official accessibility page describes the same four jobs with Xbox names. Narrator is a screen reader that gives audio descriptions for screen elements such as text and buttons. Magnifier zooms in on the screen. Colour filters assist with distinguishing colours without impacting performance, in Xbox wording, and high contrast helps distinguish items and text in Xbox built in apps and experiences. Night mode, closed captions for supported media, and a break reminder are also listed.

For controls, Xbox Controller Assist links two controllers so they can be used as if they were one controller, which lets a second person share the driving or the aiming. Button mapping is configured in the Xbox Accessories app for supported controllers, including the Xbox Wireless Controller and the Elite Series 2.

What the console cannot settle

Here is the limit, stated plainly. PlayStation says chat transcription in game chat is available only in games that support it. Chat transcription itself, at Settings, Accessibility, Chat Transcription on PS5, converts the voices of other players in parties and supported games into text, and reads aloud text entered by the player. Useful, documented, and conditional.

Xbox makes the same point in different words. Its speech transcription converts player speech from Party Chat or in game chat to text that can be read on screen, and it can read typed chat text aloud to other players. Party level support is not a promise about any one game.

PlayStation also gives players a way to check a specific game before buying or launching it. From the Games home, open PlayStation Store, select the game to open its game hub, then press the triangle button or select the side panel to view the accessibility features for that game. Use that route in launch week when the GTA VI hub carries its own list. Until a list like that is published for the game, its in game accessibility features are unconfirmed, and this guide treats them that way.

Prove it with a game already on the shelf

A settings screen can look right and still fail in play. Run this short procedure with any game already installed, ideally one with voiced cutscenes and a busy heads up display:

  1. Start the game and play a voiced scene. Read the captions against a bright background and a dark one. Adjust caption size or background opacity if either scene washes the text out.
  2. Pause in a menu with small text. Try the zoom or Magnifier route documented for the console and confirm the controls for returning to normal view are comfortable.
  3. Open a map or inventory screen where colour carries meaning. Switch the colour filter on and off and note which setting separates the markers best.
  4. Test the remapped button in ordinary play for ten minutes, not ten seconds. A layout that feels fine in a menu can fight muscle memory in a chase.
  5. Join a party or a supported game chat and turn on transcription. Confirm the text appears where it can be read without covering the centre of the screen.

What success looks like: captions stay readable in both bright and dark scenes, menu text can be enlarged without getting lost, colour coded markers separate clearly, the remapped layout survives ten real minutes, and chat text appears in a place that works. Anything that failed gets fixed now, while the fix costs an evening rather than launch day.

The day one recheck, in order

When GTA VI first launches, spend the first minutes in its own settings menu, before the opening mission sets the pace. Check subtitles and caption size inside the game, check its own button remapping if it offers one, check text size for menus and phone screens, and check separate volume levels for dialogue if they are offered. Offered is the honest word. None of those in game options is confirmed yet.

The decision rule is simple. Console settings are the floor, set once and tested. Game settings are the ceiling, unknown until the game is in hand. A player who has done the floor work can finish the ceiling work in minutes, calmly, while everyone else is still hunting for the captions toggle.
