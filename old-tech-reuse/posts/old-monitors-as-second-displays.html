Put an old monitor back to work as a second display

Repurpose · 9 min read

An old monitor feels like the easiest reuse project in the house — it is already a screen, and screens are useful. That instinct is right, and it is also how an afternoon disappears into a desk covered in cables and a monitor showing nothing. The difference between the ten-minute version of this project and the frustrating one is sequence: verify the monitor can do the job before moving any furniture, then run one clean setup procedure for the computer it will serve. This guide covers the pass-or-fail check, the Windows and Mac procedures side by side, the good second jobs for a panel that does not earn desk space, and the one class of screen that looks exactly like a spare monitor and is not one at all.

Run the pass-or-fail check first

Treat this as a spec verification: four checks, each of which can end the project honestly before it starts.

  • Power and picture. Plug the monitor into power on its own. Its menu should appear, the backlight should be even, and the image should not flicker, carry a permanent coloured line, or fade at the edges. MakeUseOf's monitor-reuse coverage makes the same point from the other side: a poor panel will not become a good primary display, so judge this one as a secondary screen from the start.
  • Inputs. Read the labels on the back — HDMI, DisplayPort, DVI, or VGA — and write down what is actually there, not what the monitor probably has. An older panel with only VGA and DVI is still usable, but it decides the cable or adapter before anything is bought or borrowed.
  • A free output. The computer needs a spare video output that can drive a second screen. A Windows setup guide checked against Microsoft Support notes that each extra monitor needs a free video port — HDMI, DisplayPort, or USB-C with video support, which a USB-C port only has when it carries a DisplayPort or Thunderbolt symbol. A plain USB-C port without that symbol will not send a picture, however well the cable fits.
  • A place to stand. If the original stand is still around, the project needs nothing else. If not, check the back for a VESA mounting plate: MakeUseOf notes that many monitors have one, so a mount or replacement stand attaches with four screws — and a mount also buys back the desk space the old stand would have eaten.

Fail on power or picture and the monitor is an e-waste candidate, not a project. Fail on the connector match and the fix is one correct cable or adapter, identified by the labels from the check — not a drawer of guesses.

Set it up on Windows, step by step

  1. Connect the monitor to the computer with the cable the check called for. On a desktop with a graphics card, plug monitors into the graphics card rather than the motherboard ports, and make sure the card supports multiple monitors.
  2. Power the monitor on and set it to the input the cable uses.
  3. Right-click the desktop and open Display settings. Both monitors should appear as numbered boxes.
  4. If the second monitor is missing, open the Multiple displays section and click Detect.
  5. Under Multiple displays, choose Extend these displays — not Duplicate, which shows the same picture twice and adds no working space — then confirm the change.
  6. Drag the numbered boxes so their arrangement matches the physical desk: old monitor on the left means box on the left. Click Apply.
  7. Click each display in turn and set its scaling separately. Mismatched size and resolution between an old panel and a newer main screen is normal — SlashGear's reuse guide notes the two do not have to match in size or resolution — and per-display scaling is what makes text comfortable on both.
  8. Press Windows key + P any time to switch modes quickly; Extend is the setting this project wants as its resting state.

Set it up on a Mac, step by step

  1. Connect the monitor with the cable or adapter the check called for, and power it on.
  2. Open the Apple menu, then System Settings, then Displays in the sidebar.
  3. Click the name of the old monitor. Apple notes these options only appear when an external display is connected.
  4. Click the Use as pop-up menu and choose the extended desktop option rather than mirroring, so the old panel holds different windows instead of a copy of the main screen.
  5. Arrange the displays so the layout matches the desk, and choose which display acts as the main one. Apple also documents a mixed setup: some displays mirroring and others extending, arranged from the same settings screen.

Good jobs for an old panel beyond a second screen

If the desk is already full, an old monitor can still earn its place. The strongest second jobs, per the reuse coverage checked for this guide: a dedicated reference screen for chat, email, or a document while the main screen holds the work (SlashGear's central example); a portrait screen — MakeUseOf highlights rotating a mounted monitor upright as especially useful for document work, since long pages read naturally; and a small dedicated media screen in a kitchen, workshop, or spare room, where SlashGear suggests connecting a streaming device to the spare monitor and treating it as a self-contained viewing station. That last job needs a thought about sound: many old monitors have weak speakers or none, so the streaming device may need the household's small spare speaker as a partner.

The trap: screens that are not monitors

The costliest misunderstanding in this niche involves the all-in-one PC: a handsome screen, a dead or outdated computer inside it, and no way to use the one as a display for the other. A Tom's Hardware forum thread on exactly this question draws the line clearly — responders explain that an all-in-one has no video-in circuitry, so without video inputs there is no way to use it as a standalone monitor; making it one would mean taking the machine apart and customizing it. The same logic applies to a laptop screen still attached to its laptop. Neither is a spare monitor, neither becomes one with the right cable, and both belong in different projects — an all-in-one can still serve as a whole second computer on its own, and a dead one belongs with the recycling guide linked below.

Troubleshooting a monitor the computer cannot see

Work the list in order; each step is cheaper than the next purchase. Confirm the monitor is on the input the cable actually uses. Reseat both ends of the cable. Use Detect in Windows display settings, or reconnect the display on the Mac and re-open Displays settings. Try the monitor on its own with a second computer or a streaming device to prove the panel works at all. Swap the cable before suspecting the port — cables are the most handled and most quietly damaged part of any setup. Check that graphics drivers are current, which the Microsoft guidance lists among its conditions for multiple monitors. If the panel fails alone as well, the verdict from the first check simply arrived late: the monitor, not the setup, is the problem.

What success looks like

Success is moving the pointer off the right edge of the main screen and watching it arrive on the old monitor, dragging a window across and having it stay put after a restart, and reading text on both screens without leaning in. The old panel holds something genuinely useful — the document being worked from, the call, the music player — while the main screen stays clear. When that is true for a week, the monitor has a job again, and the correct number of cables was one.

FAQ

Do the two monitors need to match? No. SlashGear's guide states plainly that monitors in a multi-screen setup do not have to be the same size or resolution; per-display scaling handles the difference.

Can an all-in-one PC be used as a monitor? Not as it stands — it has no video input. The forum-sourced explanation is that there is no video-in circuitry, so another computer has nothing to plug into.

Is USB-C enough by itself? Only when the port carries video. Look for a DisplayPort or Thunderbolt symbol beside it; without one, the port will not drive the monitor no matter which adapter is tried.
