Repeat Delay and Repeat Rate: Two Settings, Three Different Problems

Settings · Published 2026-11-08 · Last updated 2026-11-08

Why does a keyboard type two letters for one press, and why does holding Backspace sometimes delete half a word? Both complaints lead to the same two settings, repeat delay and repeat rate, but only one of the three usual causes is actually a settings problem. Adjusting sliders for the other two wastes an afternoon. Diagnosis comes first, and it takes about thirty seconds.

The sharp tap test: which problem is yours?

Doubled letters have two very different hardware and software causes, plus a third behaviour that is not a fault at all. A troubleshooting guide that specialises in this fault separates them with a single observation: what one sharp tap does.

One tap, three diagnoses
What you seeCauseFirst move
Two presses register for one sharp, clean tapSwitch chatter: the contact bounces and sends two presses for oneHardware route: clean the switch, check firmware, replace the switch; settings will not fix it
One press for a sharp tap, two when the finger lingers slightlyRepeat delay set too short: a normal press is being read as a held keySettings route: lengthen the repeat delay
Doubling happens in only one programThe program or an extension, not the keyboard and not the operating systemTest the same key in a plain text field before changing anything global
On a Mac, holding a letter shows a small menu of accented charactersPress and hold, working as designed: the accent menu replaces repeating for letter keysNothing is broken; doubled letters on a Mac are almost never a repeat setting

The test has a stricter form for doubtful cases. Press a key firmly, release cleanly, wait half a second, and repeat. Genuine chatter still doubles some of those presses. A short repeat delay never doubles a clean tap, because the key was never held. Ordinary text carries the same signature: chatter doubles the same letter every time, whatever the typing speed, while a settings problem doubles whichever key the finger happened to linger on. Run the tap test now, before opening any settings panel, and write down which row of the table matched. Every step after this one depends on that row.

What the two settings actually control

Microsoft's own description of the pair is short. The repeat rate controls how quickly a character repeats when you hold down a key. The repeat delay controls how long you have to hold down a key before it starts repeating. Both are adjusted with sliders. That is the whole mechanism: one timer before repeating starts, one speed once it has started.

Hold that plain description against what circulates online and a gap appears. Popular how-to pages attach exact millisecond bands to these sliders and cite resolution percentages, task time improvements and ergonomic figures for them. The controls themselves offer no numbers to set: Windows presents Repeat delay from Long to Short and Repeat rate from Slow to Fast, and macOS presents the same pair as unnumbered sliders. A recommendation to set a delay of a specific number of milliseconds cannot be followed on either system, and the statistics attached to such recommendations name no study a reader can check. Two claims of that kind were cut from this article rather than repeated. What can be verified is the slider, the direction to move it, and the result in a counted test. That is enough to tune with.

Tune Windows, one notch at a time

  1. Open the classic dialog. Press Win+R, type control keyboard and press Enter. Searching for keyboard in the Start menu reaches the same Control Panel settings. The dialog carries both sliders and a test box.
  2. Record the starting positions. Note where Repeat delay and Repeat rate sit before touching them. A change you cannot undo is a change you cannot evaluate.
  3. For doubled letters on lingering presses, move Repeat delay one notch toward Long. Change nothing else in this pass.
  4. For runaway repeats, where holding a key floods the line, move Repeat rate one notch toward Slow. Letters running away and letters doubling are different symptoms; treat the one you have.
  5. Click Apply and test in the dialog's own test box, holding a key and tapping a few, then run the counted passage test in the next section before moving another notch.

Tune macOS, and the accent menu exception

On a Mac the path is Apple menu, System Settings, then Keyboard in the sidebar. Two sliders live there: Key repeat rate, which sets how quickly supported keys repeat after repeating begins, and Delay until repeat, which sets how long the first pause lasts. Drag Delay until repeat toward Long to cure doubling on lingering presses, and Key repeat rate toward Slow if held keys run away. Moving the Key repeat rate slider all the way to the left turns key repeat off entirely, so keep it to the right of Off unless off is the goal. Changes apply immediately, with no restart or sign out, and any text field, TextEdit for example, confirms the new behaviour at once. One Mac specific warning: if the sliders cannot be changed at all, the machine may be managed by an employer or school, and the administrator is the route, not a workaround. And recall the exception from the diagnosis table: holding a letter key on macOS opens the accent menu instead of repeating, by design, so a Mac that appears not to repeat letters is usually healthy.

Measure the fix in a fixed passage

Feel is a poor instrument here, because a typist adapts to a new delay within a page and then reports that everything feels fine or everything feels wrong. Count instead:

  1. Choose one passage of about 100 words and save it. Use the same passage for every measurement.
  2. Type it once at normal speed before changing any setting. Count two things in the result: doubled letters, and characters lost to an over long Backspace hold.
  3. Change one slider by one notch, following the Windows or macOS steps above, and type the same passage again. Count the same two things.
  4. Keep the change only if the fault count falls without the other count rising. A longer delay that cures doubling but makes Backspace overshoot is a trade, not a fix; split the difference with the repeat rate instead.
  5. Stop at the first setting pair with a fault count of zero or one across the passage. Perfect exists here; chasing snappier holds past a clean count is how the doubling comes back.

What success looks like: one passage, typed at working speed, with no doubled letters and no overshot deletions, on settings you recorded and can restore.

When the settings are not the problem

If the sharp tap test pointed at chatter, the settings route is closed and the hardware route is short: clean around and inside the switch, check the maker's firmware for debounce improvements, and replace the switch on a hot swap board. While that is pending, Windows Filter Keys can act as a stopgap. Under Settings, Accessibility, Keyboard, Filter Keys has its own repeat settings and an option to ignore quick keystrokes, filtering presses that arrive too close together. It slows normal typing, so it earns its place only until the switch is fixed. The decision rule for the whole article fits in one line: clean taps that double mean hardware, lingering presses that double mean the delay slider, runaway holds mean the rate slider, and a Mac accent menu means nothing was wrong.

, Dex Carter, Tech Writer
