Typing with accents and special characters in a second language

Published 2026-10-27 · Last updated 2026-10-27

An accented character is not one thing your keyboard is hiding from you. It is the output of one of four separate systems — a numeric code, a modifier-key combination, a dead key that waits for a second keystroke, or a compose sequence — and each system wins in a different situation. The guides that frustrate people present one system, for one app or one letter, as if it were the whole answer.

Choose by frequency, not by app

The honest first question is how often the second language appears in your typing. A name with one accented letter, twice a month, needs a lookup method. Whole emails in French or Spanish, every day, need a typing method — one that keeps your hands moving instead of sending them to a code table mid-sentence. Everything below sorts itself by that line.

Know your target set first, because it is smaller than you fear. Spanish needs the five vowels with acute accents, ñ, ü, and the inverted marks ¡ and ¿. French adds grave and circumflex forms, ç, and the œ and æ ligatures. German adds umlauts and ß. A dozen or so characters per language covers ordinary writing — small enough to learn properly, too large to hunt for one at a time.

Occasional accents: codes, menus, and copy-paste

Windows Alt codes. Hold Alt and type a four-digit code on the numeric keypad, with NumLock on: Alt+0233 gives é, Alt+0241 gives ñ, Alt+0252 gives ü, Alt+0231 gives ç. The requirements matter as much as the codes — a numeric keypad and NumLock are both mandatory, which is why the method fails silently on many laptops, covered below.

Mac menus and Option keys. Press and hold a letter key and a menu of its accented forms appears; pick one. For speed, Option combinations build the accent in two steps: Option+e, then the letter, puts an acute accent on it; Option+n, then the letter, adds a tilde; Option+c gives ç directly.

Copy-paste tools. Accent reference sites list the characters for each language ready to copy. For a single character in a single document, this is genuinely the fastest method — zero setup, zero memorisation. Its cost appears only with repetition, which is the frequency line again.

Daily second-language typing: dead keys and layout switching

The US-International layout turns the apostrophe, tilde, quote, and similar keys into dead keys: press the accent, then the letter, and the combined character appears. Nothing is memorised per character, because the accent key is the accent you want. For someone writing in French or Spanish daily on an English keyboard, this is the method to commit to — it covers the full target set with a handful of accent keys.

The alternative for fully bilingual work is switching the whole layout to the language's own, which puts accented characters on dedicated keys. That trades the dead-key learning curve for a relearning curve across the entire keyboard, punctuation included. It suits writers who spend most of the day in the second language; for a split day, dead keys disturb the English layout less.

No numeric keypad? The laptop fallback set

Alt codes assume a keypad most laptops do not have — the Gmail-focused guide that popularised the codes states the requirement plainly and then leaves laptop owners stranded. Work through this set instead:

  1. Mac owners: stop here. Press-and-hold and the Option combinations need no keypad at all. The laptop problem is a Windows problem.
  2. Try Alt+X entry. Some characters sit outside the Windows code page entirely — the ł in Polish names is the standard example — and have no Alt code at all. Those characters need Unicode entry such as Alt+X where the application supports it, or copy-paste.
  3. Use copy-paste for one-offs. An accent reference site, the character copied, the document finished. Correct and immediate at low frequency.
  4. Switch to US-International for anything recurring. Dead keys need no keypad, cover the whole set, and end the lookup cycle permanently.
  5. On Linux, set a compose key. The setting lives at Settings > Keyboard > Special Character Entry > Compose Key; after that, Compose plus the accent plus the letter builds the character.

What success looks like: type the sentence your work actually contains — a Spanish greeting with ¿ and ¡, a French name with é and ç — start to finish without opening a reference page or a menu more than once. If you can, your method fits your frequency. If you stopped three times, move one tier up the list.

Four code systems, one reconciliation

Confusion in this topic usually comes from mixing systems that look alike. There are two Windows code families: the modern code-page set, typed with the leading zero — Alt+0233 — and a legacy OEM set that forum posters still carry from older machines, where á was Alt+160. Same keystrokes idea, different numbers, wrong characters when crossed.

Linux Unicode entry adds a third system with its own trap: Ctrl+Shift+u takes hexadecimal codes, not decimal. Feed it the decimal value 160 and it produces a different character than you wanted; á in that system is hex e1. HTML entities, the fourth system in the reference tables, belong to web-page source code — they are how a page displays a character, not a way to type one into a document. Keep each system in its own territory and the standard horror stories — right digits, wrong letter — stop happening.

The dead-key apostrophe trap

Dead keys have one side effect bilingual typists should meet before it meets them. The apostrophe is a dead key on US-International: pressed before a letter, it delivers an accent instead of an apostrophe. English text is full of apostrophes followed by letters — contractions, possessives — and each one risks emerging as an accented letter until the compensating habit forms: apostrophe, then space, when a plain apostrophe is wanted. It is a small tax on English typing, charged for a large discount on the second language. Daily second-language writers pay it gladly; occasional writers should stay with the lookup methods and skip the tax entirely.

Questions readers ask

How do I accent letters on a Mac? Press and hold the letter and choose from the menu, or use Option pairs: Option+e then the letter for an acute accent, Option+n then the letter for a tilde, Option+c for ç, Option+q for œ.

How do I put an accent on a letter in Windows? With a numeric keypad, Alt codes such as Alt+0233 for é, with NumLock on. Without a keypad, use Alt+X entry where supported, copy-paste for single characters, or the US-International layout for regular use.

Which Spanish accents should I learn first on an English keyboard? The acute-accented vowels á, é, í, ó, ú, plus ñ and ü — and the inverted ¡ and ¿, which English keyboards hide completely and Spanish punctuation requires.
