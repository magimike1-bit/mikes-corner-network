Three wins you can get this weekend

  • Drop the thermostat a few degrees while you sleep and while the house is empty — the easiest savings there is.
  • Seal the worst draft you can feel — usually a door or a window you sit near. Weatherstripping is a one-afternoon job.
  • Change the furnace filter if you haven't in a few months — restricted airflow makes every system work harder.
